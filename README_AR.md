# CRTE — نسخة ويب قابلة للتثبيت (PWA)

## النشر على GitHub Pages
1. فك ضغط الملف `CRTE_Web_PWA.zip`.
2. افتح مستودع GitHub الخاص بـ CRTE وارفع **محتويات هذا المجلد مباشرة إلى جذر المستودع**، وليس المجلد كطبقة إضافية.
3. تأكد أن `index.html` و`crte-app.webmanifest` و`sw.js` والأيقونات في نفس المستوى.
4. من GitHub افتح Settings ثم Pages، واختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
5. انتظر نشر الموقع، ثم افتح رابط GitHub Pages باستعمال Chrome على الهاتف.
6. اضغط زر «تثبيت تطبيق CRTE» إن ظهر. أو من قائمة Chrome ⋮ اختر «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».

## ملاحظات مهمة
- يجب فتح الموقع عبر HTTPS؛ فتح ملف HTML مباشرة من الهاتف لا يتيح تثبيت PWA.
- هذه النسخة تحافظ على هوية PWA الحالية `crte-reports-d554-2026` لتتعرف عليها الأجهزة كتحديث لنفس التطبيق على نفس عنوان الموقع. لذلك إذا كان CRTE مثبتاً من قبل من نفس الرابط، فعبارة “This app is already installed” تعني أنه مثبت بالفعل؛ افتحه من الشاشة الرئيسية ولا تحاول تثبيت نسخة مكررة.
- البيانات محفوظة محلياً داخل متصفح/تطبيق الهاتف. لا تمسح بيانات Chrome ولا تحذف التطبيق قبل تصدير/نسخ بياناتك.
- تصدير/معاينة Word يحتاجان اتصالاً بالإنترنت لتحميل JSZip وdocx-preview من CDN.
