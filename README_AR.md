# تحديث تطبيق CRTE — بدون Firebase

## الملفات
- `index.html`: التطبيق الرئيسي.
- `sw.js`: التخزين المؤقت والتحديث التلقائي.
- `crte-app.webmanifest`: إعدادات تثبيت التطبيق.
- `icon-crte-192.png` و`icon-crte-512.png`: أيقونات التطبيق.

## طريقة الرفع إلى GitHub Pages
ارفع الملفات الخمسة إلى نفس المجلد الذي يوجد فيه `index.html` الحالي، ووافق على استبدال الملفات القديمة. لا تضعها داخل مجلد فرعي جديد إلا إذا كان التطبيق منشوراً أصلاً من ذلك المجلد.

## التحديث
عند فتح التطبيق أو الرجوع إليه، يتحقق `index.html` من وجود تحديث لـ `sw.js`. إذا وجد نسخة جديدة، يفعّلها ويعيد تحميل التطبيق مرة واحدة. لفرض تحديث جديد مستقبلاً، ارفع `index.html` و`sw.js` معاً؛ ويمكن تغيير `CACHE_NAME` في `sw.js` عند الحاجة.

## Firebase
لا يحتوي `index.html` أو `sw.js` أو manifest في هذه الحزمة على أي ربط Firebase. لا ترفع ملفات إعداد Firebase أو سكريبتاته من الحزم القديمة.
المكتبتان الخارجيتان JSZip وdocx-preview ما زالتا تُحمّلان من CDN، وليستا Firebase.

## ملاحظة البيانات
هذا التحديث لا يمسح `localStorage` أو `IndexedDB`. لكنه لا يستطيع استرجاع بيانات سبق حذفها من المتصفح. احتفظ بنسخة احتياطية من مرجعيات التطبيق.
