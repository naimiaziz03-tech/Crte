# تطبيق تقرير الأشغال والاختبارات (CRTE)

تطبيق ويب يعمل كتطبيق هاتف (PWA). تملأ المعلومات ويُنتج ملف Word الأصلي مملوءا.

## الملفات (ارفعها كلها في نفس المكان)

| الملف | الدور |
|---|---|
| `index.html` | التطبيق نفسه |
| `crte-app.webmanifest` | بيانات التطبيق (الاسم والأيقونة) |
| `sw.js` | يجعل التطبيق يعمل بدون إنترنت |
| `icon-crte-192.png` و `icon-crte-512.png` | أيقونة التطبيق |
| `.nojekyll` | ملف فارغ (اختياري) |

## 1) الرفع إلى GitHub (من الهاتف أو الحاسوب)

1. ادخل إلى github.com وسجّل الدخول، ثم **New repository**.
2. الاسم مثلا `crte-app`، اجعله **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file** (أو **Add file ← Upload files**).
4. اختر الملفات الخمسة المذكورة أعلاه معا (لا ترفعها داخل مجلد)، ثم **Commit changes**.

## 2) تفعيل GitHub Pages

1. من المستودع: **Settings ← Pages**.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. Branch: **main** والمجلد **/ (root)** ثم **Save**.
4. انتظر دقيقة تقريبا، فيظهر الرابط:
   `https://اسم-حسابك.github.io/crte-app/`

## 3) تثبيت التطبيق على الهاتف

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← **تثبيت التطبيق** (أو **إضافة إلى الشاشة الرئيسية**).
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

افتح التطبيق أول مرة وأنت متصل بالإنترنت ليحفظ ما يحتاجه، وبعدها يعمل بدون إنترنت.

## الاستعمال

- املأ الحقول، ثم 👁️ لعرض الملف و 💾 لحفظه بصيغة Word.
- ☰ (أعلى الصفحة) ← **إضافة ملفات (أمثلة)**: أضف تقارير سابقة (docx) فيقترح التطبيق المحطة والموضوع والأشغال منها.
- المعلومات المدخلة والأمثلة المضافة تُحفظ في الهاتف نفسه فقط.

## التحديث لاحقا

استبدل `index.html` في المستودع (Add file ← Upload files بنفس الاسم). إذا لم يظهر التغيير، أغلق التطبيق وافتحه مرتين.
إذا غيّرت `sw.js` أو أردت فرض التحديث، غيّر `crte-v4` داخله إلى `crte-v4`.

## إذا قال المتصفح إن التطبيق «منصّب مسبقا»

1. احذف من المستودع الملفات القديمة: `manifest.webmanifest` و`icon-192.png` و`icon-512.png`، ثم ارفع الملفات الجديدة بأسمائها الجديدة.
2. احذف أي اختصار قديم لهذا الرابط من الشاشة الرئيسية.
3. افتح الرابط من جديد في Chrome ← ⋮ ← **تثبيت التطبيق**.
تنبيه: لا تمسح «بيانات الموقع» لـ github.io كله، لأنها مشتركة مع بقية تطبيقاتك على نفس الحساب.

## إذا بقيت رسالة «منصّب مسبقا»

1. افتح Chrome واكتب في شريط العنوان `chrome://webapks` لترى التطبيقات المنصّبة فعلا. إن وجدت تطبيقا قديما لهذا الرابط فاحذفه من إعدادات الهاتف ← التطبيقات.
2. الحل الأضمن: أنشئ مستودعا **جديدا** باسم مختلف (مثلا `crte-app2`) وارفع إليه الملفات نفسها وفعّل Pages، ثم ثبّت من الرابط الجديد. المسار الجديد يعتبره المتصفح تطبيقا جديدا.
3. افتح الرابط في تطبيق Chrome نفسه (⋮ ← Open in Chrome)، وليس داخل نافذة مصغّرة من تطبيق آخر.
4. للتأكد أن النسخة الجديدة هي المحمّلة: افتح ☰ ويجب أن ترى في أسفل القائمة «الإصدار 4».

## زر التثبيت داخل التطبيق (الإصدار 4)

افتح ☰ ← قسم **التثبيت**: يظهر زر «📲 تثبيت التطبيق» إذا سمح Chrome بالتثبيت، ويظهر تحته عنوان الصفحة الحالي. إن لم يظهر الزر فأرسل العنوان لمعرفة السبب.
